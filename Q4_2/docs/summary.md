# 발표 요약: 규칙으로 언어를 정의할 수 있는가?

## 1. 한 줄 결론

**규칙은 미리 생각해 둔 표기는 거의 틀리지 않지만, 생각하지 못한 표기나 문맥은 놓친다.**

- 정보 추출: 뽑은 것 중 99~100%가 맞았고(정밀도), 뽑아야 할 것의 94~96%를 찾았다(재현율).
- 감성 분석: 리뷰 1,000개 중 75.2%를 맞혔다. 사전에 있는 단어가 나오는 리뷰는 84.8%, 사전 단어가 하나도 없는 리뷰(전체의 37.5%)는 59.2%로 동전 던지기에 가깝다.
- 머신러닝(TF-IDF)과 비교: 학습 데이터 1,000개짜리 모델과 비슷하고, 10,000개로 학습하면 모델이 이긴다(80.3%).

## 2. 먼저 알아 둘 용어

| 용어 | 쉬운 뜻 |
| --- | --- |
| 정규식 | 문자열 모양을 적는 규칙. `\d{3}`은 "숫자 3개"라는 뜻 |
| 정규화 | 표기가 달라도 같은 값이면 한 형식으로 맞추는 것. `2024년 3월 15일`, `2024.3.15` → 둘 다 `2024-03-15` |
| 정밀도 (Precision) | 내가 "찾았다"고 한 것 중 진짜 맞은 비율. 높으면 헛것을 덜 잡는다 |
| 재현율 (Recall) | 찾아야 할 것 중 실제로 찾은 비율. 높으면 덜 놓친다 |
| F1 | 정밀도와 재현율을 하나로 합친 점수 |
| 정확도 (Accuracy) | 전체 중 맞힌 비율 |
| 오탐 | 아닌 걸 맞다고 잡은 것 (예: 연도 범위 `1998-2024`를 전화번호로 잡음) |
| 개발셋 / 홀드아웃 | 개발셋은 규칙을 고치면서 계속 보는 문제집, 홀드아웃은 끝날 때까지 안 보고 한 번만 푸는 시험지 |
| 형태소 분석기 (Okt) | 문장을 단어와 품사로 쪼개고 기본형으로 바꿔 주는 도구. `맛있지 않았어요` → `맛있다` + `않다` |
| 감성 사전 | 단어마다 점수를 매긴 표. `재밌다 +2`, `지루하다 -2` |
| 부정어 / 강조어 | 부정어는 뜻을 뒤집는 말(`안`, `않다`, `없다`), 강조어는 세기를 바꾸는 말(`정말` ×1.5, `좀` ×0.5) |
| 이중부정 | 부정이 두 번 나와 서로 상쇄되는 것. `재밌지 않을 수 없다` → 재밌다 |
| TF-IDF | 단어가 자주 나오는 정도로 문장을 숫자로 바꾸는 방법. 여기에 분류 모델을 붙여 긍정/부정을 학습시킴 |
| 데이터 누수 | 시험 문제가 공부 자료에 섞여 들어가 점수가 부풀려지는 것 |
| 시드 | 무작위 뽑기를 다시 해도 같은 결과가 나오게 하는 번호. 시드 5개 = 다르게 5번 뽑아 평균 |
| Aspect (측면) | 한 문장 안에서 대상별로 감성을 따로 보는 것. `음식은 맛있는데 가격이 비싸요` → 음식 긍정, 가격 부정 |
| 마스킹 / 누출 | 마스킹은 개인정보를 `*`로 가리는 것, 누출은 못 가리고 그대로 남은 것 |

## 3. 요구사항 → 해결 과정

| 과제가 요구한 것 | 뭐가 어려웠나 | 어떻게 풀었나 | 결과 |
| --- | --- | --- | --- |
| 이메일·전화·날짜·금액·URL 뽑기 (패턴마다 표기 3가지 이상) | 한국어는 `02-1234-5678로`처럼 조사가 붙어서 단어 끝을 찾는 기본 기능(`\b`)이 안 먹힌다. 날짜·전화·카드번호는 생긴 게 비슷하다 | 표기마다 규칙을 따로 14개 만들고, 앞뒤 글자를 직접 검사. 여러 규칙이 같은 곳을 잡으면 더 긴 쪽을 채택 | 개발셋 정밀도 0.992 / 재현율 0.937 |
| 뽑은 값을 정해진 형식으로 돌려주기 | `1억 2천만원`, `+82-10-…`, `2024. 1. 5.`처럼 같은 값을 여러 방식으로 쓴다 | 정규식으로 연·월·일 같은 조각을 따로 꺼낸 뒤, 종류별 함수로 형식을 맞춤 | 날짜 `YYYY-MM-DD`, 금액 정수+통화, 전화 하이픈 통일 |
| 테스트 문장 50개 이상, 정밀도·재현율 측정 | 규칙 만든 사람이 시험 문제도 내면 점수가 잘 나올 수밖에 없다 | 문장 생성기로 115개를 만들고, 규칙을 보지 않은 AI 에이전트에게 40개를 따로 쓰게 함 | 처음 보는 문장에서도 정밀도 1.000 / 재현율 0.957 |
| 틀린 사례 5개 이상 분석 | 왜 틀렸는지를 매번 같은 기준으로 나눠야 한다 | 틀린 이유를 자동으로 5가지(지원 안 하는 표기, 범위 잘못 잡음, 형식 변환 오류, 다른 규칙과 겹침, 오탐)로 분류 | 10건 분석 |
| 감성 단어 200개 이상, 영화 분야 단어 30개 이상 | 형태소 분석기가 단어를 기본형으로 바꾸므로 사전도 그 모양으로 써야 매칭된다 | 사전을 기본형으로 작성. 영화 리뷰에서 긍정·부정 리뷰에 각각 많이 나온 단어를 통계로 골라 후보로 씀 | 285개 (영화 분야 59개) |
| 부정어·강조어·이중부정 처리 | 부정이 어디까지 영향을 주는지, 언제 두 부정이 상쇄되는지 정해야 한다 | 뒤에 오는 부정어(`않다`)는 앞 2단어까지, 앞에 오는 `안/못`은 바로 다음 말만 뒤집음 | 부정어가 작동한 리뷰의 정확도 0.511 → 0.809 |
| 리뷰 100개 이상으로 평가, 규칙 넣기 전후 비교 | 규칙을 고칠 때 본 데이터로 평가하면 점수를 믿을 수 없다 | 고칠 때 보는 데이터와 평가 데이터를 완전히 분리. 평가는 마지막에 한 번만 | 리뷰 1,000개, 규칙 조합 5가지 비교 |
| 틀린 사례 10개 이상 분석 | "점수가 0이라 틀림"과 "반대로 판단해서 틀림"은 원인이 다르다 | 둘을 나누고, 반대로 판단한 20건을 원인별로 정리 | 원인 9가지 |
| [보너스] 마스킹 / TF-IDF 비교 / 측면 분석 | 마스킹은 하나만 놓쳐도 누출, TF-IDF는 데이터 양에 따라 결과가 바뀜, 한 문장에 좋고 나쁨이 섞임 | 누출 검사, 학습 데이터 크기별로 5번씩 반복, 문장을 절로 나눠 대상별로 판단 | 6절 참고 |

## 5. 무엇을 왜 그렇게 정했나

| # | 정한 것 | 안 고른 방법 | 이유 |
| --- | --- | --- | --- |
| 1 | 변환된 값과 위치로 채점 | 원문 글자 그대로 비교 | 과제가 형식 변환을 요구하므로 변환이 틀려도 오답으로 잡아야 한다 |
| 2 | 규칙이 못 잡는 어려운 표기도 정답에 넣음 | 잡을 수 있는 것만 정답으로 | 규칙이 어디까지 못 하는지 숫자로 보여 주려고 |
| 3 | 규칙을 안 본 AI에게 시험 문제를 따로 쓰게 함 | 내가 만든 문제만 사용 | 내 문제에서 어려운 표기 빼고 전부 맞아서 점수가 부풀려졌다고 의심했다 |
| 4 | URL은 영문·숫자만 허용 | 한글 주소도 허용 | `…/123에서`처럼 조사가 붙는 경우가 더 흔하다. 한글 URL을 놓치는 건 감수 |
| 5 | 대표번호는 15xx·16xx·18xx만 | 15xx~19xx 전부 | 연도 범위 `1998-2024`를 전화번호로 잘못 잡는 걸 발견 |
| 6 | 영화 리뷰를 후보 뽑기용 / 규칙 고치기용 / 평가용 셋으로 나눔 | 한 묶음으로 고치고 평가 | 평가 데이터를 보고 고치면 점수를 믿을 수 없다 |
| 7 | 고치기용 데이터에서 틀린 걸 보고 부정어 규칙을 3번 수정 | 처음 규칙 유지 | `안 하고 봤는데 꿀잼`(꿀잼을 뒤집으면 안 됨) 같은 오류 → 0.721 → 0.737 |
| 8 | 영화 리뷰에서 `슬프다`, `ㅠㅠ`는 긍정으로 | 일반적인 뜻(부정) | 실제로 긍정 리뷰에 더 많이 나온다(`슬프다` 6배, `ㅠㅠ` 2.5배). 감동했다는 뜻 |
| 9 | 평가 중에 찾은 문제(`드럽게`, `됐다`를 `돼다`로 잘못 바꾸는 형태소 분석기 오류)는 기록만 함 | 바로 고침 | 평가 데이터를 보고 고치면 점수가 오염된다. 분석기의 한계로 남김 |
| 10 | TF-IDF 비교에 10,000개를 추가하고 5번씩 반복 | 10/100/1,000개로 한 번씩 | 1,000개에서 둘이 비슷해져서 그 뒤 흐름을 보려고. 10개짜리는 뽑을 때마다 결과가 크게 달라진다 |

## 7. 결론: "규칙으로 언어를 정의할 수 있는가?"

- **형식이 정해진 정보(이메일, 날짜, 금액)는 규칙으로 정의할 수 있다.** 거의 틀리지 않고, 왜 그렇게 판단했는지 설명할 수 있다.
- **감정이나 문맥은 규칙으로 다 정의할 수 없다.** 사전에 있는 단어가 나오면 머신러닝만큼 맞히지만, 사전에 없는 단어나 반어법에서는 무너진다.
- **같은 규칙도 쓰임새에 따라 중요한 점수가 다르다.** 정보 추출은 헛것을 안 잡는 게(정밀도) 중요하지만, 개인정보 가리기는 하나라도 놓치면 유출이라 빠짐없이 찾는 게(재현율) 중요하다.
- **다음 단계는 섞어 쓰기다.** 형식이 정해진 정보는 규칙으로, 감정 같은 열린 표현은 머신러닝으로. 감성 분석도 사전 단어가 있으면 규칙, 없으면 TF-IDF로 판단하면 된다.
